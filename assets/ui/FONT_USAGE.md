# UI font roles

Fonts are assigned by task, not applied globally:

- **Press Start 2P** — large page titles only.
- **Boxy Bold** — short English action buttons at display sizes. Never IDs or data.
- **Atkinson Hyperlegible Mono Regular** — English body copy and secondary labels.
- **Atkinson Hyperlegible Mono Bold** — participant IDs, protocol IDs, keypad glyphs,
  timers and result values. Its monospaced forms and slashed zero distinguish
  `0 / O / D` and `1 / I / L`.
- **Sprout Lands pixel font** — decorative in-world captions and input hints.
- **IPix 12px** — Chinese text.

The other fonts in the supplied Mikiz pack were reviewed but not bundled:

- Fipps forbids redistribution of the font software.
- Free Pixel identifies itself as a non-commercial demo.
- 8-bit Arcade has conflicting license statements between its README and
  embedded metadata.
- Monster Friend Fore has no explicit redistribution license in the package.

Atkinson Hyperlegible Mono is licensed under SIL OFL 1.1; its complete license
is stored in `atkinson_hyperlegible_mono_OFL.txt`.
