# Dyadic Force 五关扩展需求文档

## 1. 文档信息

- 文档类型：游戏与实验功能需求
- 适用项目：Dyadic Force
- 当前阶段：开发前需求确认
- 本期范围：旧项目的五个正式关卡、可复用关卡组件、实验日志与验收标准
- 不在本期范围：新游戏项目、视野不对称玩法、语音分析、新角色或新场景主题

## 2. 项目目标

在保留现有“双人合力滚球”核心操作、像素美术、分屏、生命值、计时、重生和实验日志系统的基础上，重做五个正式关卡，使完整游玩流程稳定接近 10 分钟，并分别诱发以下五类合作行为：

1. 共同起步；
2. 共同减速；
3. 弯道协调；
4. 失衡补偿；
5. 路线选择。

本期不追求在单关内堆叠多种机制。每关只保留一个主要挑战，通过增加地图长度、提供数次自然重复机会来延长游戏时间和提高数据质量。

## 3. 已确认的设计约束

### 3.1 美术约束

- 唯一允许新增的可见关卡物体是“可撞开的门”。
- 门优先复用现有围栏、木质像素素材或由现有素材组合完成，不要求制作新的完整素材包。
- 其他关卡只使用现有草地、水面、围栏、树、灌木、石头、地面箭头、球、角色和终点传送门。
- 不新增停车台、刹车标线、风险标志、信号灯、实验区域、风暴特效、奖励宝箱或专用仪表。
- 后台分析区域不得在画面中显示。

### 3.2 游戏体验约束

- 关卡首先必须像连续的双人滚球游戏，而不是明显的实验任务集合。
- 不向玩家显示同步率、领导者、受扰玩家、补偿反应、风险等级或实验条件。
- 不使用固定且容易被察觉的重复节奏，例如每隔 4 秒必定扰动、每个弯完全相同。
- 正式关卡的说明只描述游戏目标，不解释研究指标。
- 地图允许较长，但机制必须简单；长度来自同一能力的自然重复，不来自额外机关。
- 除门外，不得为本期玩法引入需要玩家重新学习的新交互对象。

### 3.3 实验约束

- A/B 始终按参与者身份记录，不因 P1/P2 或左右屏交换而改变。
- 物理帧不是独立样本；帧数据用于计算门、弯道、扰动和岔路等事件级指标。
- Baseline 与 Perturbation 必须使用同一地图结构和相同的合格分析路段。
- 关键行为必须可由原始输入、位置、速度和事件日志重算。
- 隐藏触发可以伪随机，但必须由可保存的种子或序列编号决定，以便复现。

## 4. 目标流程与时长

| 环节 | 目标时长 |
| --- | ---: |
| 教程 | 60–90 秒 |
| 第 1 关：共同起步 | 70–90 秒 |
| 第 2 关：共同减速 | 70–90 秒 |
| 第 3 关：弯道协调 | 70–90 秒 |
| 第 4 关：失衡补偿 | 70–90 秒 |
| 第 5 关：路线选择 | 70–90 秒 |
| 说明、载入与结算 | 60–120 秒 |

完整流程目标为约 8.5–11 分钟。正式关默认限时建议从 110–120 秒开始试玩，不应为了凑时长故意要求重复失败。

## 5. 组件总体规划

本期组件分成可见玩法组件和不可见测量组件。只有门属于新增可见玩法组件。

### 5.1 BreakableGate：可撞门

#### 功能目的

在第 1 关提供三次共同加速和撞击目标，同时记录两人的共同起步和持续合力表现。

#### 玩家可见行为

- 门横跨主路线，球不能绕过。
- 成功时门打开、向两侧倒下或破开，球可以继续前进。
- 失败时门晃动并使球轻微反弹。
- 不显示同步度、失败原因或玩家责任。
- 三扇门外观和操作规则一致。

#### 成功判定

每扇门在球正面接触时检查碰撞前短窗口，默认窗口建议为 400 ms。必须同时满足：

- 球沿门法线方向前进；
- 正向速度达到该门阈值；
- A、B 在窗口内均有有效输出；
- 双方平均施力方向大体一致；
- 双方合力主要朝向门，而非横向擦碰。

启动时间差只记录，不作为严格失败条件。只要两人最终形成持续共同合力，即可撞开。

#### 三扇门的初始参数建议

| 门 | 正向速度阈值 | 双方方向余弦 | 双方有效发力要求 |
| --- | ---: | ---: | ---: |
| Gate 1 | 低 | ≥ 0.60 | 各自活动占窗口 ≥ 50% |
| Gate 2 | 中 | ≥ 0.70 | 各自活动占窗口 ≥ 60% |
| Gate 3 | 中高 | ≥ 0.75 | 各自活动占窗口 ≥ 65% |

具体数值必须通过物理试玩校准，不把表中阈值视为最终常量。

#### 碰撞与伤害

- 成功撞门不扣血。
- 失败撞门也不扣血。
- 门产生音效、震动或震屏不等于伤害。
- 门旁普通围栏和地图边界仍按现有规则扣血。
- 不允许通过关闭整关伤害来实现门免伤。
- 碰撞系统必须能够识别碰撞对象或伤害类别，只对门跳过伤害结算。

#### 状态

- `closed`：有碰撞，等待尝试；
- `opening`：判定成功，立即取消阻挡，播放短演出；
- `opened`：永久通过，不重复触发。

#### 事件日志

- `gate_attempt`
- `gate_failed`
- `gate_opened`

事件至少包含：`gate_id`、碰撞位置、正向速度、碰撞强度、A/B 力、方向余弦、活动占比、结果、失败分类、`damage=0`。

失败分类只用于后台，例如：

- `speed_low`
- `missing_A`
- `missing_B`
- `direction_conflict`
- `off_axis`

#### 防重复要求

- 单次物理接触只记录一次尝试。
- 球必须离开门的接触范围后，才能记录下一次失败尝试。
- 成功后不得再产生该门尝试事件。

### 5.2 RouteSegmentZone：不可见路段标注

#### 功能目的

把长地图划分成可分析的路段，而不向玩家显示实验区域。

#### 推荐类型

- `start`
- `acceleration`
- `brake_approach`
- `left_turn`
- `right_turn`
- `recovery`
- `perturb_candidate`
- `choice_approach`
- `choice_branch`

#### 功能要求

- 仅用于检测球心进入和离开，不产生碰撞或视觉。
- 记录进入、离开时间与路段 ID。
- 每帧日志可写当前主要路段 ID 和类型。
- 路段允许不同长度，不要求玩家感知到规律。

### 5.3 PerturbationController：隐藏失衡控制器

#### 功能目的

在第 4 关对某一玩家施加短暂输入增益下降，并保证事件可平衡、可复现、不会形成明显固定规律。

#### 触发要求

- 只在预先标记的合格路段中触发。
- 球进入候选路段后，还需满足稳定性条件：近期无碰撞、未重生、双方有一定活动、球速处于有效范围。
- 不在玩家明显失控或刚刚受伤时叠加扰动。
- 若候选路段内始终不合格，应记录跳过原因，不在危险位置强行补触发。

#### 扰动要求

- 每关目标 2 次，隐藏序列可允许部分版本有第 3 次，但正式实验开始前必须固定协议。
- 单次持续约 2.0–3.0 秒。
- 输入增益初始建议为 0.55–0.65。
- 两次扰动间至少保留约 5 秒恢复时间。
- A/B 先后顺序在双人组之间平衡。
- 玩家界面不显示具体开始时间、剩余时间或受扰者。

#### Baseline 行为

- Baseline 在相同候选路段执行假触发，不改变输入增益。
- 仍记录 `sham_perturbation` 事件，便于按地图位置比较。

#### 事件日志

- `perturb_candidate_enter`
- `perturb_on`
- `perturb_off`
- `sham_perturbation`
- `perturb_skipped`

### 5.4 ChoiceForkTracker：隐藏岔路追踪器

#### 功能目的

在第 5 关连续游玩中识别双方最初偏好的路线、分歧、妥协和最终选择，不弹出投票界面。

#### 功能要求

- 岔路入口设置一个不可见的 `choice_approach` 区域。
- 在进入后读取 A/B 第一段持续有效输入，而非单帧抖动。
- 将输入投影到两个分支方向，判断初始分支偏好。
- 记录双方是否一致、冲突持续时间、谁先改变方向。
- 球进入某一分支的确认线后锁定最终选择。
- 若球退回入口并转入另一支，记录 `branch_reversal`。

#### 事件日志

- `choice_started`
- `choice_preference_A`
- `choice_preference_B`
- `choice_conflict`
- `branch_committed`
- `branch_reversal`

### 5.5 CollisionCategory：碰撞分类支持

现有伤害仅根据球速突变量判断，无法区分门和普通障碍。本期必须补充以下分类能力：

- `ordinary_obstacle`：正常伤害；
- `breakable_gate`：记录碰撞但伤害为 0；
- `world_boundary`：正常伤害；
- `non_damaging_trigger`：不参与物理碰撞，仅作检测。

实现方式不作强制规定，但伤害系统最终必须获得足够信息判断本次冲击是否免伤。

## 6. 教程关需求

教程继续承担基础操作教学，不加入正式门、失衡或路线选择机制。

### 地图要求

- 保持短且宽；
- 包含一次自然起步、轻微绕行和终点停车；
- 使用现有资源；
- 不追求正式实验级重复次数。

### 教学内容

- 两人同向推动更容易起步；
- 可以通过力度和方向调整路线；
- 转弯前适当减速；
- 撞击普通障碍会受伤；
- 将球停在传送门上完成关卡。

教程数据可作为熟悉程度和初始能力参考，但不与正式关主要指标混合。

## 7. 第 1 关：共同起步——三门长直道

### 核心目标

通过三扇门提供三次清晰但不中断流程的共同加速机会，观察双方是否逐渐形成共同启动节奏。

### 地图结构

```text
出生 → 起步直道 → Gate 1 → 长直道 → Gate 2 → 更长直道 → Gate 3 → 收尾直道 → 终点
```

### 地图要求

- 总长度初始建议 1,900–2,300 px，试玩后按目标时长调整。
- 主路线以横向直道为主，仅允许轻微视觉偏移，不设置急弯或窄道。
- 通道宽度建议约 220–280 px。
- 门的有效通过口建议约 160–200 px。
- 门间距建议约 450–650 px。
- 门前至少保留足够的平直加速距离。
- 门后保留安全缓冲，避免开门动画后立刻撞障碍。
- 路边装饰不得侵入球的主要行驶带。
- 三扇门不能被绕过。

### 难度曲线

- Gate 1 用于无文字教学，宽松判定；
- Gate 2 使用标准判定；
- Gate 3 仅小幅提高速度和共同发力要求；
- 不给三扇门增加不同谜题或不同操作规则。

### 伤害规则

- 三扇门始终免伤；
- 其他普通碰撞仍正常扣血；
- 失败撞门的主要代价是时间和重新组织，不是生命值。

### 主要派生指标

- 每门尝试次数；
- 每门首次成功率；
- A/B 启动时间差；
- 碰撞前共同活动时长；
- 方向余弦与力度差；
- 撞门正向速度；
- 门 1 到门 3 的改善趋势；
- 谁更常先发起冲刺。

## 8. 第 2 关：共同减速——长直道回转场

### 核心目标

通过长直道自然鼓励加速，再用路线转折迫使双方共同减速。不得加入停车台或新的可见任务物体。

### 地图结构

```text
出生 → 长直道 A → 宽回头弯 → 长直道 B → 较紧回头弯 → 长直道 C → 终点
```

### 地图要求

- 总长度按中心线路程建议约 1,800–2,300 px。
- 至少包含两段可充分建立速度的长直道。
- 第一处回转区较宽，用于自然学习；第二处稍紧，用于正式测量。
- 不设置门、分叉或输入扰动。
- 不设置必须停住才能通过的区域。
- 使用现有灌木墙、围栏和树形成边界。
- 转弯外侧保持普通碰撞伤害，形成自然速度代价。
- 不用箭头标出刹车起点；箭头只提示整体路线方向。

### 后台测量

在每个回转前后设置不可见路段：

- 长直道基线；
- 入弯前减速段；
- 弯心；
- 出弯恢复段。

### 主要派生指标

- 入弯速度；
- A/B 开始减小输入的时间；
- A/B 反向制动起点；
- 制动启动差；
- 路线过冲距离；
- 外侧碰撞次数；
- 出弯恢复时间；
- 谁先发起有效制动。

## 9. 第 3 关：弯道协调——林间长弯道

### 核心目标

在一条较长、外观自然且不完全规则的路线中提供可比较的左右弯，观察领导发起、跟随和纠偏分工。

### 地图要求

- 中心线路程建议约 1,900–2,400 px。
- 至少包含 6 个主要弯道，其中左右弯数量平衡。
- 后台至少形成两组可比较配对：缓左/缓右、较紧左/较紧右。
- 成对弯道不必相邻，避免形成明显测试规律。
- 弯道之间穿插长度不同的直道和恢复空间。
- 可使用一个宽阔回转，但不得让整关只剩连续 180° 折返。
- 通道物理宽度必须保证直径约 88 px 的球能够稳定通过；最低通道宽度建议不低于 150–170 px。
- 不加入门、扰动或岔路决策。
- 全部使用现有树、灌木、石头和箭头。

### 主要派生指标

- 各弯转向起点差；
- 谁先发起转向；
- 弯中方向一致性；
- 平均和峰值路线误差；
- 出弯过冲；
- A/B 纠偏贡献；
- 左右弯领导者；
- 领导权切换率与稳定性。

## 10. 第 4 关：失衡补偿——宽路长程

### 核心目标

在地图本身较简单的情况下，观察一方输入能力短暂下降后另一方的补偿、恢复和过度纠正。

### 地图要求

- 中心线路程建议约 1,900–2,400 px。
- 主路整体宽阔，以直道、缓弯和开阔恢复段为主。
- 不设置窄井、密集障碍、门或路线分叉。
- 至少提供 3 个后台候选扰动路段，以便从中成功触发 2 次主要扰动。
- 候选路段外观不得完全相同，位置和间隔不得呈现明显周期。
- 触发区域不可见，不新增风暴或信号干扰美术。
- 关卡文字只做游戏化提醒，例如“这里的控制可能不太稳定”，不得告知时间、次数或受影响玩家。
- HUD 不显示紫色时间窗或具体扰动状态。

### 条件要求

- Baseline 与 Perturbation 使用相同地图。
- Perturbation 按隐藏序列平衡 A/B 受扰顺序。
- 触发应基于路线位置和稳定性，不使用固定整秒周期。
- 序列版本与随机种子写入 session 或 trial 数据。

### 主要派生指标

- 未受扰者补偿反应时；
- 补偿方向准确度和峰值；
- 扰动后最大路线偏差；
- 恢复时间；
- 过度补偿与往返纠偏；
- 扰动前后领导者变化；
- 被扰者恢复后搭档撤力时间。

## 11. 第 5 关：路线选择——双岔路长地图

### 核心目标

在连续操作中自然形成两次“短窄路线与长宽路线”的共同选择，测量双方最初偏好、冲突和妥协。

### 地图结构

```text
出生 → 过渡路段 → 岔路 1 → 汇合长路 → 过渡弯道 → 岔路 2 → 收尾路段 → 终点
```

### 地图要求

- 总中心线路程因路线不同而变化，安全路线版本建议约 2,000–2,500 px。
- 设置两个主要岔路，不使用弹窗、投票或风险标签。
- 每个岔路包含：
  - 较短但较窄的路线；
  - 较长但较宽的路线。
- 两条路线最终汇合，不影响能否完成关卡。
- 第一个岔路的短窄路线位于一侧，第二个岔路交换方向，降低键位和方向偏好。
- 两个岔路的外观构成应不同，但只复用现有资源。
- 不增加宝箱、分数奖励或额外道具；短路线的收益是节省时间，窄路线的成本是碰撞风险。
- 分支本身不加入急弯、门或扰动，避免路线选择与操作难度严重混淆。
- 岔路入口应给玩家足够观察和表达方向的距离。

### 后台判定

- A/B 初始偏好使用持续有效输入判定；
- 双方都未形成偏好时允许为空，不强制分类；
- 球穿过分支确认线后确定最终路线；
- 若退回再换路，记录反转而非覆盖原始选择。

### 主要派生指标

- A/B 初始路线偏好；
- 初始一致率；
- 冲突持续时间；
- 最终路线；
- 谁先改变方向；
- 谁的初始偏好成为最终选择；
- 分支反转次数；
- 风险路线选择率；
- 当前血量、剩余时间和上一段碰撞对选择的影响。

## 12. LevelDef 数据需求

## 15. 自动测试需求

### 15.1 门组件

- 双方同向满推可以撞开 Gate 1。
- 单人推不能稳定撞开标准门。
- 双方反向输入不能撞开门。
- 成功和失败撞门均不扣血。
- 撞门旁普通墙仍扣血。
- 同一次接触不重复记录尝试。
- 开门后碰撞体及时失效，球不会被隐形阻挡。

### 15.2 地图可达性

- 五关出生点到终点均存在球心可行路径。
- 第 1 关除开门外无绕行路径。
- 第 2、3、4 关最低通道宽度满足球体通过要求。
- 第 5 关每个岔路的两条分支都可独立到达汇合点。

### 15.3 扰动

- Baseline 不改变增益但记录假触发。
- Perturbation 只对指定玩家生效并按时恢复。
- 暂停、重生、退出和关卡结束会恢复双方增益。
- 同一序列版本可重复得到相同受扰顺序。
- 碰撞或重生后的不合格候选触发会延后或跳过。

### 15.4 岔路追踪

- 单帧输入抖动不生成偏好。
- 两人选择不同分支时记录冲突。
- 最终进入分支后只提交一次选择。
- 退出已进入分支并改走另一支会记录反转。

### 15.5 日志

- 新事件符合固定列和受控枚举要求。
- A/B 映射在交换 P1/P2 后仍正确。
- 原始 CSV 可解析，派生结果可重算。
- 中途退出和重开不会覆盖旧 trial。

## 16. 人工试玩验收

### 第 1 关

- 玩家在不读实验说明的情况下能够通过第一次失败理解撞门规则。
- 三扇门不会因要求过严造成长时间卡关。
- 单人不应轻易带着另一人通过全部门。
- 三门之间有明显加速距离，整关不是连续贴门。

### 第 2 关

- 玩家会在至少一处回转前自然减速。
- 地图难点来自速度控制，不来自卡窄缝。

### 第 3 关

- 左右转向均有足够样本。
- 玩家不会明显感到地图在机械地左右重复。

### 第 4 关

- 玩家能感觉偶尔不稳定，但难以准确预测固定发生时间。
- 扰动强度足以产生可测补偿，又不至于必然撞墙。

### 第 5 关

- 两条路线都有人选择，不能出现几乎所有人固定选同一路线。
- 玩家无需停下来读说明即可理解两条路都能前进。

### 总体

- 教程加五关的中位完成时长接近 10 分钟。
- 关卡失败率不能高到大量双人组缺失后半程数据。
- 玩家主观体验应是逐渐变难的滚球冒险，而非一组明显的实验小任务。
